# Pickel Sells ATL

Next.js real-estate site for Bobby Pickel, focused on Atlanta buyers and sellers.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Verification

```bash
npm run lint
npm test
npm run test:a11y
```

The site includes responsive media, SEO metadata, JSON-LD, sitemap and robots routes, an accessible contact path, reduced-motion support, and Playwright axe checks.
